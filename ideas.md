# AI Operator design direction

## Theme: Mission Control / Quiet Precision
A premium dark operations console for turning natural-language requests into verified work. The interface favors calm certainty over sci-fi theatrics: deep navy surfaces, acid-lime readiness signals, warm amber attention states, and restrained cyan for active execution.

- **Design movement:** editorial control room with high-contrast data surfaces.
- **Core principles:** evidence over optimism, readable state, one decisive next action, no fake capabilities.
- **Color philosophy:** near-black navy foundation; off-white type; lime for healthy/verified; amber for blocked/approval; coral for failure.
- **Layout paradigm:** left rail for navigation, wide command surface, compact evidence cards.
- **Signature elements:** numbered stage rail, pulse dot, monospaced audit timestamps, status chips.
- **Interaction philosophy:** every action returns visible state and explanation; unsafe actions pause.
- **Animation:** short opacity/translate transitions, no distracting loops except status pulse.
- **Typography:** Inter/system sans for UI; IBM Plex Mono for audit and technical evidence.
- **Brand essence:** a dependable operator that never pretends.
- **Brand voice:** concise, specific, transparent.
- **Wordmark/logo:** bracketed operator mark, [A], used as a simple geometric favicon.
- **Signature brand color:** #C8F56A.
